# Benign calibration refresh evidence

Existing calibration-only refresh on NSL-KDD with UNSW-NB15 as the non-shift control, AR and R3-L, seeds 10-14: twenty per-run records and the stored summary. Refreshed C and evaluated E are disjoint; C contains labelled test-period benign traffic, not an unlabelled method. FPR restoration and alarm failure are distinct from detection performance; this is the original diagnostic, not the later training-refresh experiments. No training, scoring, or analysis was rerun to assemble the bundle.

Only nonnumeric provenance identifiers and local/remote paths are relabelled. Numeric JSON tokens, all confusion matrices, scientific-content/source hashes, and adaptation/limitation wording outside identifiers are unchanged. Provenance script aliases are descriptive metadata, not additional executable entry points. The private source-to-release mapping remains outside this bundle. SHA256SUMS covers every result file.
