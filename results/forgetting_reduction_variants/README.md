# Forgetting reduction variants evidence

Existing V1a/V1b/V2/V3 development screen on UNSW-NB15 and CIC-IDS-2017, seeds 1-2, with stored AR controls: 17 of 20 attempted cells have complete trajectories. CIC V2 seed1 and V3 seeds1-2 retain partial records only and are not called complete. Only V1a/V1b advanced historically; their confirmation with AR controls is complete at 45/45 cells on UNSW, CIC-2017 and CSE-2018, seeds 15-19. Individual checkpoint sidecars are included only where they already existed; raw model weights are not bundled. The original CSV tables retain all negative/incomplete and non-inferiority outcomes. These are earlier variants, not the later F1-F5 screen. No training, scoring, or analysis was rerun to assemble the bundle.

Only nonnumeric provenance identifiers and local/remote paths are relabelled. Numeric JSON tokens, all confusion matrices, scientific-content/source hashes, and adaptation/limitation wording outside identifiers are unchanged. Provenance script aliases are descriptive metadata, not additional executable entry points. The private source-to-release mapping remains outside this bundle. SHA256SUMS covers every result file.

Relabeling is applied only where needed. Files already free of internal identifiers remain byte-for-byte copies; a per-file relabeling note states the sanitization policy, not that an edit was required in every record.
