# Neural replay controls evidence

Existing neural AR, Replay-BS, Freq and WACB on UNSW-NB15 and CIC-IDS-2017, seeds 10-14: forty completed per-run records. Neural AR is not the stateless tree method. Original model, exposure, memory, correction, calibration and adaptation limitations remain in each record. Other methods and datasets are deliberately outside this requested bundle. No training, scoring, or analysis was rerun to assemble the bundle.

Only nonnumeric provenance identifiers and local/remote paths are relabelled. Numeric JSON tokens, all confusion matrices, scientific-content/source hashes, and adaptation/limitation wording outside identifiers are unchanged. Provenance script aliases are descriptive metadata, not additional executable entry points. The private source-to-release mapping remains outside this bundle. SHA256SUMS covers every result file.

Relabeling is applied only where needed. Files already free of internal identifiers remain byte-for-byte copies; a per-file relabeling note states the sanitization policy, not that an edit was required in every record.

The `ar_*` records retain the original experimental method identifier `aacil_nogkd_wa`; neural AR is its historical paper label, not the stateless tree method. No method identifier, architecture or adaptation limitation has been changed to make the comparison look different.

Retained hashes bind the original scientific/source records, not newly serialized provenance-renamed identities. SHA256SUMS verifies the delivery bytes.
